# 🍽️ Swiggy UI Clone (React + Tailwind CSS)

This is a front-end **Swiggy clone UI** built using **React** and **Tailwind CSS**, designed to replicate the look and feel of the original Swiggy website. This project focuses purely on the user interface and layout, ideal for learning and showcasing modern front-end development skills.

---

## 🚀 Features

- ✅ Fully responsive and mobile-first layout
- 🍕 Home page with promotional hero section and featured categories
- 🏬 Restaurant listing with cards, ratings, and filters
- 🔍 Search bar with dynamic styles and icon integration
- 🛒 Stylish cart UI with item count (UI only)
- 🌙 Dark mode support (optional)
- 💨 Built with utility-first Tailwind CSS classes
- ⚛️ Modular React components for scalability and maintainability

---

## 🛠️ Tech Stack

- **React** (via functional components and hooks)
- **Tailwind CSS** for utility-first styling
- **React Icons** or **Heroicons** for SVG icons
